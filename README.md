One fortune-cookie line for developers, written to `/output/entry.txt`.

See the competition on [make.fun](https://make.fun) — entry for "Fortune Cookie Wisdom for Developers" (make.fun competition `u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44`).

## The line

> The bug you chase at midnight was written by the you who swore this code was finished.

## Run

```sh
python3 main.py
```

The program is deterministic, uses only the Python standard library, and writes exactly one line (86 characters) to `entry.txt` in the directory given by `OUTPUT_DIR` (default `/output`).
